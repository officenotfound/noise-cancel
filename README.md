# QuietMic (working name)

System-wide AI noise cancellation for Windows (rain on a steel roof, barking, honking, distant yelling), built to replace Krisp.
**Start with [BUILD_SPEC.md](BUILD_SPEC.md)**; section 13 has the measured Phase 0 results.

## Status
- Phase 0 (benchmark harness + test set + model comparison): **done on macOS**. Windows/i5-8250U timing still needs to be measured.
- Phase 1 (tray app, WASAPI, VB-Cable): not started.

## Layout
- `crates/qm-dsp` – denoiser wrappers (DeepFilterNet3 / DFN3-LL via tract, RNNoise via nnnoiseless), platform-independent
- `crates/qm-bench` – CLI: speed, delay and SI-SDR for one file/model
- `scripts/` – model + test-data fetchers, test-set mixer, full benchmark sweep, Windows bench pack
- `results/RESULTS.md` – latest benchmark tables (`results/listen/` has before/after WAVs, regenerated by `run_bench.py`)

## Reproduce
```sh
scripts/fetch_models.sh && scripts/fetch_testdata.sh
python3 -m venv .venv && .venv/bin/pip install numpy scipy pystoi
.venv/bin/python scripts/make_testset.py
cargo build --release -p qm-bench
.venv/bin/python scripts/run_bench.py
```
